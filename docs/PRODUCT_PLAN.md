# OSUNNOTE 제품 실행계획 v0.1

상태: 구현 승인 대기  
작성일: 2026-10-22

## 제품 한 줄 정의

OSUNNOTE는 장문 창작자가 아이디어를 구조화하고, 방해 없이 쓰고, 어떤 기기에서도 안전하게 이어 쓰며, 자기 글을 표준 형식으로 소유할 수 있게 하는 local-first 글쓰기 작업실이다.

## MVP

### 포함

- 이메일/소셜 로그인과 개인 작업공간
- 프로젝트 → 폴더 → 문서 계층
- Markdown 기반 편집과 일반 서식 단축키
- 로컬 자동 저장, 오프라인 편집, 다기기 동기화
- 충돌 시 원문 보존과 비교/복구
- 검색, 태그, 상태, 목표 글자 수
- 문서 버전 기록과 복원
- 집중 모드와 기본 테마/타이포그래피 설정
- Markdown, TXT, DOCX, PDF 내보내기
- Web PWA, iOS, Android
- 계정 데이터 다운로드와 계정 삭제
- 무료 베타 및 향후 무료+월/연간 구독 기반

### 제외

- 실시간 공동 편집과 댓글
- 생성형 AI 집필 기능
- EPUB 및 전문 출판 조판
- 플러그인/API 마켓
- 경쟁 제품 전용 파일 형식의 완전 호환

## MVP 완료 기준

- 오프라인 작성 후 네트워크 복귀 시 글이 손실 없이 동기화된다.
- 두 기기에서 같은 문서를 편집해도 어느 버전도 자동 폐기되지 않는다.
- 10만 자 문서와 문서 1,000개 프로젝트에서 핵심 흐름이 안정적으로 동작한다.
- Web/iOS/Android에서 가입, 작성, 검색, 복원, 내보내기, 탈퇴 흐름을 완료한다.
- 베타에서 crash-free session 99.5% 이상을 달성한다.
- 본문이 로그와 분석 도구에 유출되지 않음을 검증한다.

## 데이터 모델 초안

- `User`, `Identity`, `Device`
- `Workspace`, `Membership`, `Subscription`
- `Project`, `Node`, `Document`, `DocumentMeta`
- `DocumentSnapshot`, `ChangeOperation`
- `Tag`, `NodeTag`, `Asset`
- `WritingSession`, `ExportJob`, `AuditEvent`

모든 주요 엔터티는 ID와 생성/수정 시각을 가진다. 삭제 가능한 데이터는 복구 기간 동안 soft delete한다. `ChangeOperation`은 device, base revision, operation, idempotency key를 기록한다.

## 개발 단계

| 단계 | 예상 기간 | 종료 조건 |
|---|---:|---|
| 제품 발견 | 2주 | 인터뷰, 성공지표, 상표 조사, PRD 승인 |
| 기반/기술 검증 | 2주 | 편집기·자동 저장·동기화 PoC, 위협 모델, CI |
| Web 코어 경험 | 4주 | 트리, 편집, 검색, 태그의 Web 알파 |
| 동기화/복구 | 4주 | 오프라인, 충돌, 버전, 장애 테스트 통과 |
| 모바일 | 4주 | iOS/Android 핵심 흐름과 접근성 |
| 내보내기/구독 | 3주 | 내보내기, 영수증 검증, 계정 관리 |
| 비공개 베타 | 3주 | 실제 기기 베타와 안정성 기준 통과 |
| 심사/출시 | 2~4주 | 양대 스토어 심사와 단계적 출시 |

핵심 인력 4~6명 기준 총 24~26주 예상이다. 인력과 출시일이 달라지면 범위를 다시 산정한다.

## 출시 전 필수 확인

- 개인정보처리방침, 이용약관, 구독·환불 안내
- App Store App Privacy와 Google Play Data safety의 실제 데이터 흐름 일치
- 앱 내 계정 삭제와 데이터 내보내기
- Apple/Google 인앱결제, 구매 검증, 복원 및 취소/환불 상태 처리
- Sign in with Apple 적용 필요 여부
- 최소 권한, 접근성, 실제 기기, 크래시/ANR 테스트
- 심사용 계정, 리뷰 노트, 앱 설명, 스크린샷, 지원 URL
- 앱 서명 키, 인증서, 서비스 계정의 조직 소유 및 이중 인증
- 백업 복원, 장애 대응, 단계적 출시와 중단 기준
- 제출 직전 Apple/Google 최신 정책 재확인

## 지식재산 원칙

제품 아이디어와 일반적인 글쓰기 기능은 자체 코드와 자체 UX로 구현한다. 경쟁 제품의 소스, 자산, 화면, 문구, 아이콘, 고유 명칭, 고유 흐름, 비공개 포맷을 복제하지 않는다. 모든 외부 의존성과 자산은 라이선스를 검토하고 고지한다.

## 구현 승인 게이트

다음 기본안을 사용자가 승인하거나 수정한 뒤 앱 코드를 생성한다.

1. 1차 고객: 장문 창작자
2. 출시 언어: 한국어 우선, 국제화 구조 포함
3. 수익 모델: 초기 무료 베타 후 무료+구독
4. 보안: 표준 저장/전송 암호화로 MVP, 종단간 암호화는 별도 검증
5. 일정: 4~6명 기준 약 24~26주

승인 직후 첫 스프린트에서는 모노레포 기반, 편집기 Markdown round-trip, 로컬 자동 저장/복구, revision 동기화의 기술 검증을 수행한다.
